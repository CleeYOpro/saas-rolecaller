# RoleCaller - SaaS Attendance Tracking for Rural Schools

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?style=for-the-badge&logo=vercel)](https://vercel.com/cleeyopros-projects/v0-your-saa-s-saa-s-landing-page)


## About RoleCaller

RoleCaller is a revolutionary offline-first SaaS solution designed specifically for rural and remote schools in India. Our mission is to ensure that education doesn't depend on internet connectivity, providing teachers with powerful tools to track student attendance even in the most challenging environments.

In partnership with Friends Missionary Prayer Band (FMPB), RoleCaller empowers educators to capture attendance data anywhere - deep in forests, on hilltops, or in areas with no internet connectivity - and sync it when connectivity becomes available.

## Key Features

### 📴 100% Offline Capability
Teachers can mark attendance on their smartphones without any internet connection. All data is securely stored on the device until it can be synced.

### 💝 Free Forever
As an open-source initiative, RoleCaller is completely free for all mission schools. We believe every child deserves to be seen and counted.

### 👀 Every Child Seen
Our platform ensures no student gets lost in the system. Quietly tracks attendance patterns to identify students at risk of dropping out.

### ☁️ Smart Sync
When internet becomes available, the app automatically syncs all saved data in the background without any manual intervention.

### 📊 Data-Driven Insights
Administrators gain valuable insights through real-time attendance dashboards, helping them support students who need it most.

## How It Works

1. **Offline Attendance**: Teachers use our simple mobile app to mark attendance, even in areas with no internet connectivity
2. **Local Storage**: All data is securely stored on the device until internet is available
3. **Automatic Sync**: When connectivity is restored, data automatically syncs to the cloud
4. **Actionable Insights**: Administrators access real-time dashboards to monitor attendance and identify at-risk students

## Technology Stack

- **Frontend**: Next.js 16, React 19, TypeScript
- **Styling**: Tailwind CSS, Radix UI
- **Animations**: Framer Motion
- **Deployment**: Vercel
- **Development**: v0.app (AI-powered UI generation)

## Development

To run this project locally:

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
